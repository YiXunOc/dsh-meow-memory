# 工具参考

meow-memory 注册的七个记忆工具，含全部参数与返回。工具分三档权限：**读**（search / read / find_similar / project）、**写**（remember / update / dream）、**目录**（home）。

> 工具描述与返回文案跟随 `promptLang` 语言包，因此下表中的参数说明在英文/葡语语言包下会是英文/葡语。

---

## 工具速查

| 工具 | 档 | 用途 |
|---|---|---|
| `memory_remember` | 写 | 写入一条记忆：必填 content / project / keywords / importance |
| `memory_search` | 读 | 关键词检索（BM25 × 近期权重） |
| `memory_project` | 读 | 取回某项目的完整注入段落（项目全景） |
| `memory_find_similar` | 读 | 查重与冲突检测 |
| `memory_read` | 读 | 按 id 读取单条完整元数据 |
| `memory_update` | 写 | 按 id 修正 status / importance / goal / keywords / content |
| `memory_dream` | 写 | 手动触发本窗口的记忆整理（与 `/dream` 命令同语义） |
| `memory_home` | 目录 | 查看 / 切换全局数据目录 |

> 另有 `/dream` 用户命令（输入框直接敲），与 `memory_dream` 工具同语义，不受峰时抑制。

---

## `memory_remember` — 写入

必填 `content` / `project` / `keywords` / `importance`；**缺失会逐个报错并引导重填**。写入时自动去重合并，并返回读回确认（关键词、项目归属）。

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `content` | string | — | 必填。记忆正文 |
| `project` | string | — | 必填。项目名；全局信息填全局标记 |
| `keywords` | string[] | — | 必填。检索用关键词（命中基于关键词而非全文） |
| `importance` | integer | `1` | 必填。权重，参与命中打分 |
| `level` | enum | `fact` | 层级：`soul` / `user` / `project` / `fact` / `lesson` / `topic` / `rules` |
| `subcategory` | enum | — | 仅 `level=project` 有效：`overview` / `structure` / `decisions` / `quotes` / `ops` / `todo` |
| `goal` | string | — | 目标句（`topic` 层用） |
| `corrected` | boolean | `false` | 是否属于纠正类记忆 |

**返回**：`ok` / `id` / `level` / `merged`（是否合并进已有条目）/ `keywords` / `project`。

> `keywords` 缺失与「传了但解析不出关键词」返回**不同错误信息**（issue #24）。

---

## `memory_search` — 检索

BM25 × 近期权重。默认 `k=10`，取法为**前 5 条最相关（不排除已见与本 session 建立的记忆）+ 后 5 条从排名后续绕开已见补齐**，按记忆时间戳排序。

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `query` | string | — | 必填。查询词 |
| `level` | string | — | 按层级过滤 |
| `project` | string | — | 按项目过滤，**支持逗号多选（OR 语义）** |
| `status` | string | — | 按状态过滤，**支持逗号多选（OR 语义）** |
| `days` | integer 1–3650 | — | 只搜最近 N 天 |
| `k` | integer 1–50 | `10` | 返回条数上限 |
| `content_max` | integer 0–5000 | `300` | 单条内容截断长度 |

**返回**：`note` + `hits[]`。每条 hit 是**检索元数据视图**——归属 + 完整 id + 相对时间 + 关键词列表，**不含原文**。

> 浏览项目全貌请用 `memory_project`，不要用 search 拼。

---

## `memory_project` — 项目全景

取回某项目的完整注入段落。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `project` | string | **是** | **project 参数必填**——你要看哪个项目的信息？ |

**输出规则**：

- 非 `todo` 子标签：`active` 条目全部
- `todo` 子标签：`active` 全部为「To do list：」+ `stale`（已完成）按 `updated_at` 取最近 5 条为「已完成：」
- 组内按记忆时间戳旧 → 新；只拼 `content` 纯文本

**副作用**（重要）：调用非全局、非多项目参数时，会**锚定当前会话的 project** —— 之后的关键词命中立即跟进该项目；同时把该项目记入本会话"查阅过"清单，供会话压缩后重注入项目全景。

---

## `memory_find_similar` — 查重

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `id` | string | — | 必填。基准记忆 id |
| `k` | integer 1–20 | `5` | 返回相似条目数 |
| `content_max` | integer 0–5000 | `200` | 内容截断长度 |

---

## `memory_read` — 读单条

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | 记忆 id |

返回单条完整元数据（含 keywords / status / importance / goal / 时间戳等字段）。

> 只由 `memory_read` 单条读取触发「查阅过」留痕；`memory_project` 全景不标记（第三轮项目总结会专门复查）。

---

## `memory_update` — 修正

| 参数 | 类型 | 说明 |
|---|---|---|
| `id` | string | 必填 |
| `content` | string | 改写正文 |
| `status` | enum | `active` / `archived` / `stale` |
| `importance` | integer | 权重 |
| `goal` | string | 目标句 |
| `project` | string | 项目归属 |
| `keywords` | string[] | 手动修正关键词 |

> `updated_at`（记忆时间戳）在 `memory_update` 刷新或 dream 封存时更新；对外展示的时间戳一律是 `updated_at`。

---

## `memory_dream` — 手动整理

无参数（整理范围固定为本窗口）。与 `/dream` 命令同语义，**不受峰时抑制**。

> 已有整理在进行中会明确提示，不会重复启动。

---

## 附加 UI 折叠规则

**纯文本消息才折叠（带附件的保持原样）。**

适用于「注入折叠 UI」：首轮长期记忆与每消息关键词命中的注入文本在前端折叠成横条（与用户气泡同宽），点开可查看注入全文；用户 prompt 以气泡形式直接显示。带附件的消息保持原样、不参与折叠。

会话列表 dream 图标的优先级：**呼吸灯 > 跳过 > 月牙**（有新活动即移除）。

---

## `memory_home` — 全局数据目录

查看或切换实例级全局数据目录（日志 / window-index / prompts 覆盖层 / migrate 状态）。

| 参数 | 类型 | 说明 |
|---|---|---|
| `target` | string | 省略 = 只查看当前目录与预设落点；要切换则传预设标记或绝对路径 |

**三个预设标记**：

| 标记 | 落点 |
|---|---|
| `default` | 平台用户主目录 |
| `dsh-storage` | `<DSH home>/storages/meow-memory` |
| `plugin-root` | `<插件根>/storage` |

**切换行为**：同盘移动 / 跨盘复制；**旧目录绝不自动删**；目标目录已有内容则直接启用、不覆盖；非法 `target` 不会误切（明确报错并保持当前目录）。切换失败时数据未受影响，可稍后重试。

> 若本机有多个 dsh 实例共享旧目录，切换后请同步修改它们的设置。

## 层级与子类目

| 层级 | 含义 |
|---|---|
| `soul` | AI 自身 |
| `user` | 用户基本信息与偏好 |
| `project` | 项目信息（带 `subcategory`） |
| `fact` | 原子事实 |
| `lesson` | 教训与纠正 |
| `topic` | 进行中的讨论话题（带目标句 `goal`） |
| `rules` | 设计原则与行为准则 |

`project` 的 `subcategory`：`overview` / `structure` / `decisions` / `quotes` / `ops` / `todo`。

**全局标记**：当前语言包 `labels.md` 的 `project.global` 值（中文包为「全局」，英文包为 `"global"`）。它随 `promptLang` 走——否则英文包里模型写的 `"global"` 会被当成一个叫 global 的项目，全局 rules 不再注入、项目列表里凭空多出一个项目。

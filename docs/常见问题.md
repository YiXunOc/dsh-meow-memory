# 常见问题

装不上、检索不准、行为不符合预期时先查这里。

## 安装

### 首次 `dsh plugin add` 失败，提示 `allowBuilds`

pnpm ≥10 默认会阻止安装期的构建脚本：首次 `add` 可能失败并提示 `allowBuilds`，按提示把输出的键加进 profile 的 `pnpm-workspace.yaml` 后重跑即可。

本包通过 `prepare` 脚本在安装时自动编译（`node build.mjs`），所以这个构建步骤是必需的。

### Node 版本要求

`node:sqlite` 为运行时依赖：**Node ≥22.13 默认可用**；**22.5–22.12 需加 `--experimental-sqlite`**。无原生模块依赖。

### 手动安装（开发者，任意 DSH 安装，无需 npm）

1. 把本包复制（或软链）到 profile 的 `node_modules`：

   ```sh
   mkdir -p ~/.dsh/profiles/web/node_modules
   ln -s /path/to/meow-memory ~/.dsh/profiles/web/node_modules/meow-memory
   ```

   （Windows：`New-Item -ItemType Junction ...` —— NTFS junction，无需管理员权限。）

2. 把 `meow-memory` 加进 profile `package.json` 的 `dsh.profile.bundles`。

3. 重启 `dsh web`。新会话自动加载插件。

### 卸载

```sh
dsh plugin --profile web remove meow-memory
```

## 检索与命中

### 为什么第一条消息没有关键词命中

**首轮不跑关键词命中**（命中从第二轮起）。首轮改为注入长期记忆快照，这是刻意设计——详见 [设计说明](设计说明.md)。

即使首条用户消息与插件通知消息同批到达（如 approval policy 变更通知），快照仍会紧贴插入到真实用户消息之前、命中绝不提前。

### 检索命中率低 / 命中不到

按可能性排序：

1. **`promptLang` 没显式配置**。`promptLang` 同时影响模型写记忆条目用的语言——关键词按条目语言提取。**因此首次使用时请显式配置它**。配置值就是子目录名，**逐字匹配**：填一个 `src/prompts/` 里不存在的名字（例如 `pt`）不会报错，而是静默落回中文包。
2. **条目关键词质量差**。命中基于**条目关键词**（LLM 提取或自动 bigram）而非全文——全文匹配噪音大。可用 `memory_update` 的 `keywords` 手动修正。
3. **命中的是"清单"而非"答案"**。`memory_search` 返回的是检索元数据视图（归属 + id + 相对时间 + 关键词），**不含原文**；要看原文用 `memory_read`，要看项目全貌用 `memory_project`。

> 条目与查询语言不一致不会"杀检索"：BM25 分词自 v0.20.0 起语言无关（类别路由）；`en` 模式额外启用英语归一化（停用词过滤 + Porter 词干还原），屈折变化不影响命中（`tokenizers` 能命中存为 `tokenizer` 的条目）。

### 用户闲聊时命中了别的项目

未锚定时命中只搜全局（用户闲聊不误伤）。`memory_remember/search/update/project` 带 project 参数即锚定该会话的当前项目。

### 全局记忆该填什么

全局适用的信息 project 填**全局标记**（当前语言包 `labels.md` 的 `project.global` 值：中文包为「全局」，英文包为 `"global"`），与留空=未标记区分。同时适用于多个项目时用英文逗号分隔（如 `"dsh, femo"`）——检索/命中按"包含当前项目名 或 全局"判定。

## 整理（dream）

### dream 一直不触发

按顺序检查：

| 可能原因 | 说明 |
|---|---|
| 窗口未空闲够 | 窗口空闲 ≥ `idleMinutes`（默认 **180 分钟 = 3 小时**）才进入允许触发状态 |
| 处在峰时抑制 | **峰时抑制**（按 `timeZone` 计算，默认北京时间）：`suppressWindows` 默认 09:00–12:00、14:00–18:00，及各自开始前 `suppressLeadMinutes`（默认 15）分钟内不触发；峰时结束后下一个检查周期自动触发 |
| 该窗口已被跳过 | 会话行的「…」菜单里可恢复 |
| 窗口太旧或已归档 | 无 live agent 且超过 24h 的旧窗口、以及已归档的会话，均不处理 |
| 窗口最后发言早于上次 dream | 每个最后发言晚于上次 dream 的窗口才整理 |

进行中的 dream 不被打断。

### 怎么立刻整理，不等空闲

在输入框敲 `/dream` 立即手动唤起本窗口的记忆整理（与 `memory_dream` 工具同语义，**不受峰时抑制**）。dsh 命令平面执行、不发给模型，输入 `/` 的补全菜单里直接可见；已有整理在进行中会明确提示，不会重复启动。

### 某个窗口不想被自动整理

左侧边栏该会话行的「…」菜单里点一下**「跳过梦境整理记忆」**即可，再点**「取消跳过梦境整理记忆」**恢复。被跳过的窗口不再被空闲定时器自动 dream（`/dream` 与 `memory_dream` 手动触发不受影响），会话列表里显示**静音灰「月牙+斜杠」**图标、一眼可辨。跳过状态持久保存、重启不丢；双实例共享同一记忆库，状态天然一致。

### dream 图标看不懂

| 图标 | 含义 |
|---|---|
| **淡黄色小月牙 🌙** | dream 整理过记忆且之后无新对话新信息 |
| **白→金呼吸灯月牙** | dream 轮进行中（与 dsh 状态点并存、月牙居左，不与正常工作混淆） |
| **静音灰「月牙+斜杠」** | 该会话被跳过梦境整理（取消跳过自动回落） |

优先级：**呼吸灯 > 跳过 > 月牙**。有新活动即移除。

### 一次性任务的工作区污染了记忆库

用 `disabledWorkspaces` 把它列进去：cwd 精确匹配（路径归一：斜杠统一 + 去尾斜杠 + 大小写不敏感），命中的工作区**完全停用记忆**（读/整理/写全拒，**含手动 `/dream`**）。

## 数据与目录

### 记忆库在哪里

- 工作区级：`<工作区>/<projectDir>/memory.db`（`projectDir` 默认 `.dsh-meow`）
- 会话级留痕：`<工作区>/<projectDir>/sessions/<id>.json`
- 实例级全局目录（日志 / window-index / prompts 覆盖层 / migrate 状态）：由 `homeDir` 决定

### 怎么换全局数据目录

对 AI 说一句即可（`memory_home` 工具），零代码零重启。或在设置页 / `homeDir` 配置项指定预设标记或绝对路径。

切换 = 同盘移动 / 跨盘复制；**旧目录绝不自动删**；目标目录已有内容则直接启用、不覆盖；非法 `target` 不会误切（明确报错并保持当前目录）；失败时数据未受影响，可稍后重试。

> 若本机有多个 dsh 实例共享旧目录，切换后请同步修改它们的设置。

### 想要备份

设置 `backup.enabled: true`：每次 dream 收尾把 `memory.db` 快照轮转到 `memory.db.bak`（`VACUUM INTO` 一致性备份，按 mtime 判增量）。**注册期消费，改动需重载**。

### 旧 `PROJECT.md` 会不会丢

`autoMigrate` 默认 `true`：首次打开库时自动迁移旧 `PROJECT.md`。

## 扩展与语言

### 界面语言和 prompt 语言为什么不一样

插件界面文案（折叠横条、打点气泡、会话菜单项、设置页）走独立的 **UI 文案层**，跟随 DSH 的「设置 → 通用 → 语言」；而注入给模型的 prompt 仍按 `promptLang` 走。两层互不影响。

老宿主（无 locale 服务）自动降级为浏览器语言 + 内置字典，最终落 `zh`。

### 怎么加一门界面语言

加字典文件 + 在 `SUPPORTED_UI_LOCALES` 加一行（不改 UI 代码），详见 [`src/i18n/README.md`](../src/i18n/README.md)。

### 怎么加一门 prompt 语言

prompt 文案是数据文件（`src/prompts/`），一门语言一个子目录，改文件即生效、无需改代码——详见 [`src/prompts/README.md`](../src/prompts/README.md)（含贡献指南与 `npm run check-lang` 自查）。实例级自定义：`<home>/.dsh-meow/prompts/<lang>/` 下放同名槽位文件即可覆盖（可只覆盖部分）。
